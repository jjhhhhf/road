## 專案簡介

**路口排雷**是一個社群驅動的道路缺陷回報平台，使用者可以透過 GPS 定位，回報路面坑洞、紅綠燈故障、違規停車等各類道路危險，並附上照片佐證。社群成員可以對回報進行投票認可，讓最緊急的問題獲得更高的能見度，協助政府與相關單位優先處理。

### 設計理念

- **低門檻回報**：開啟手機即可 GPS 定位並拍照回報
- **社群驗證**：投票機制讓真實危險得到更多關注
- **遊戲化激勵**：成就系統與 XP 點數鼓勵持續參與
- **在地化設計**：以臺灣（繁體中文）為核心使用場景，預設城市為高雄市

## 功能特色

### 地圖檢視
- 以 Leaflet.js 呈現互動式地圖
- 各類型危險以不同顏色的自訂標記顯示
- 依當前位置列出附近的道路危險

### 道路危險回報
- **GPS 定位**：自動偵測或手動選擇位置
- **危險分類**：路面坑洞、紅綠燈、違規停車等 6+ 種類別（含 emoji 圖示）
- **嚴重程度**：5 級評分（輕微 / 一般 / 中度 / 嚴重 / 緊急）
- **照片上傳**：拍照或選擇現有圖片，最大 6MB

### 社群互動
- 對回報帖子進行**投票 / 認可**，提升危險的能見度
- **留言討論**：針對危險狀況及修復進度發表評論
- 查看危險的**修復狀態**追蹤

### 成就與遊戲化
- **9 種成就徽章**，依據回報數、得票數、修復數等條件解鎖
- XP 經驗值系統記錄貢獻度
- 個人資料頁顯示最多 3 個自訂標籤與所在城市

### 使用者帳號
- 帳號註冊 / 登入（Session-based 驗證）
- 自訂暱稱、個人識別碼、所在城市
- 偏好設定（附近通知、自動 GPS、夜間護眼）

### 管理員後台
- 檢視所有危險回報、帖子、留言
- 刪除不當內容
- 修改管理員密碼

## 技術架構

| 層級 | 技術 |
|------|------|
| **後端執行環境** | Node.js |
| **Web 框架** | Express.js v4.19.2 |
| **資料庫** | SQLite（透過 sql.js v1.10.3，含檔案持久化） |
| **檔案上傳** | Multer v1.4.5-lts.1 |
| **驗證機制** | Session Cookie（7 天有效），管理員使用 HTTP Basic Auth |
| **密碼加密** | PBKDF2-SHA256，100,000 次迭代 |
| **前端** | 原生 JavaScript（無需建置工具），單頁應用 (SPA) |
| **地圖** | Leaflet.js v1.9.4 |
| **字型** | Google Fonts（Outfit、Noto Sans TC） |
| **PWA** | Service Worker，支援離線快取 |

## 快速開始

### 前置需求

- **Node.js** v14 或以上版本
- **npm**

### 安裝步驟

```bash
# 1. 複製專案
git clone https://github.com/jjhhhhf/road.git
cd road

# 2. 安裝依賴套件
npm install

# 3. 啟動伺服器
npm start
```

伺服器預設在 `http://localhost:3000` 啟動。

### 存取網址

| 頁面 | 網址 |
|------|------|
| 主應用程式 | http://localhost:3000 |
| 管理員後台 | http://localhost:3000/admin |

> 管理員後台需輸入帳號密碼（預設：`admin` / `admin1234`），請務必在生產環境中修改。

## API 文件

### 驗證 (Authentication)

| 方法 | 路徑 | 說明 |
|------|------|------|
| `POST` | `/api/auth/register` | 註冊新帳號 |
| `POST` | `/api/auth/login` | 登入，回傳 Session Cookie |
| `POST` | `/api/auth/logout` | 登出 |
| `GET` | `/api/me` | 取得目前登入使用者資訊 |

### 應用狀態

| 方法 | 路徑 | 說明 |
|------|------|------|
| `GET` | `/api/state` | 取得完整 App 狀態（危險清單、帖子、使用者資料、統計） |

### 使用者資料

| 方法 | 路徑 | 說明 |
|------|------|------|
| `PUT` | `/api/profile` | 更新個人資料（名稱、識別碼、城市、標籤） |
| `PUT` | `/api/prefs` | 更新使用者偏好設定 |

### 危險回報

| 方法 | 路徑 | 說明 |
|------|------|------|
| `POST` | `/api/report` | 建立危險回報（含可選照片） |
| `POST` | `/api/upload` | 上傳照片檔案 |

### 社群互動

| 方法 | 路徑 | 說明 |
|------|------|------|
| `POST` | `/api/posts/:postId/vote` | 對帖子投票 |
| `DELETE` | `/api/posts/:postId/vote` | 取消投票 |
| `POST` | `/api/posts/:postId/comments` | 新增留言 |

### 管理員（需 Basic Auth）

| 方法 | 路徑 | 說明 |
|------|------|------|
| `GET` | `/api/admin/hazards` | 列出所有危險回報 |
| `GET` | `/api/admin/posts` | 列出所有帖子 |
| `GET` | `/api/admin/comments` | 列出所有留言 |
| `DELETE` | `/api/admin/hazards/:hazardId` | 刪除危險回報 |
| `DELETE` | `/api/admin/posts/:postId` | 刪除帖子 |
| `DELETE` | `/api/admin/comments/:commentId` | 刪除留言 |
| `PUT` | `/api/admin/password` | 修改管理員密碼 |

## 資料庫結構

資料以 SQLite 儲存於 `data.sqlite`，伺服器啟動時自動建立並遷移 Schema。

| 資料表 | 用途 |
|--------|------|
| `users` | 使用者帳號（含加鹽雜湊密碼） |
| `sessions` | 登入 Session（7 天有效期） |
| `user_profiles` | 使用者個人資料（名稱、識別碼、城市） |
| `user_profile_tags` | 成就標籤（每人最多 3 個） |
| `user_prefs` | 使用者偏好設定 |
| `hazards` | 道路危險回報（含座標、類型、顏色） |
| `posts` | 社群討論帖子（關聯危險） |
| `post_votes` | 投票記錄（防重複投票） |
| `comments` | 帖子留言 |
| `admins` | 管理員帳號 |

## 管理員後台

存取 `http://localhost:3000/admin`，使用 HTTP Basic Auth 登入。

後台功能：
- 總覽所有危險回報、帖子與留言
- 一鍵刪除不當內容
- 修改管理員密碼

> **安全提示**：請在首次部署時立即透過後台或環境變數修改預設密碼 `admin1234`。

## PWA 支援

本應用支援 Progressive Web App 標準：

- **可安裝**：在手機瀏覽器點選「加入主畫面」即可安裝為 App
- **離線支援**：Service Worker 快取核心資源，斷網仍可使用基本功能
- **主題色**：紅色 `#FF3B4E`（強調色）+ 深色 `#0C0D12`（背景色）
- **語言**：`zh-TW`（臺灣繁體中文）
